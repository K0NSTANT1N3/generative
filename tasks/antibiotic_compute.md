Released labels instead haveNG38,650 andSA39,390;NG has50checkpoints and`num_folds=5,ensemble_size=10`, whereasSA has20checkpoints. This affects an exact reproduction and is not merely rounding.

The saved timestamp is a start/config timestamp, not runtime. SA's zero-byte config prevents analogous recovery without additional checkpoint inspection.

Cell links upstream corpora, but direct line counts are **1,488,640** for [F-VAE ChEMBL TXT](https://raw.githubusercontent.com/wengong-jin/multiobj-rationale/master/data/chembl/all.txt), **71,032,918bytes**, and **1,799,433** for [hgraph ChEMBL TXT](https://raw.githubusercontent.com/wengong-jin/hgraph2graph/master/data/chembl/all.txt), **84,418,662bytes**. The exact Cell-specific data cleaning/snapshot and generator modifications are not all pinned/released.

Both Cell VAE pretraining and de novoJT-VAE sampling should be distinguished from **search/evaluation**: main methods say40million latent samples,28,534,490unique outputs. ASKCOS uses4CPUs and60seconds **search budget per compound**; that is neither a GPU training time nor a free chemical-validity runtime. GenericSMILES parsing is far cheaper but does not prove synthesizability or antibacterial activity.

**Natural-product-data caveat:** The 2025 main text describes ChEMBL, natural products, and antibiotics as three chemical domains. However, the original generator config uses MEGx as `target_space` for FCD/UMAP reference, while the fine-tuning input is the 131 antibiotic SMILES file. It does **not** show separate MEGx generator training in this configuration. Report the authors' prose and the actual released config separately. Do not say MEGx is necessarily required proprietary training data. The public MEGx reference file can be downloaded immediately; a distinct open license from the vendor was not found. Since the file is bundled in a MIT repository but ChEMBL upstream remains CC BY-SA, a blanket MIT label for all third-party data would be unsupported.

The 5.82M parameter count is a **calculation from confirmed architecture**, not a value stated in the paper: `4*1024*(71+1024+1)+4*256*(1024+256+1)+(256+1)*71+4*(71+256)=5,820,515`, including batch-normalization statistics. Approximately 1.33M parameters are trainable when the first LSTM is frozen. The 40 epochs are fine-tuning; no renewed 365k pretraining claim should be made.

Predictor code also exposes a reproducibility concern: [`ranking/de_novo_pipeline.py`](https://github.com/sieber-lab/AIbiotics/blob/main/ranking/de_novo_pipeline.py) calls `TabularPredictor.fit(train_df, tune_test_data=test_df)`, uses no explicit time limit, and the README specifies `--test-size 0.8`. These deserve checking against the installed AutoGluon API. A five-minute environment and full-pipeline assurance would be unfounded. This is a code-inspection finding, not an observed execution failure.

## Constraint verdict and research gap implications

Neither full published antibiotic pipeline is a confirmed fit for **T4 / 16 GB, under 4 GPU-hours, setup under 5 minutes**. JACS's small LSTM fine-tuning is computationally promising after a PyTorch/current Keras port and limited sampling. Cell's full VAE pretraining and screening of millions of molecules exceed this budget. All compute estimates above are broad, uncalibrated planning estimates.

The Cell collaboration acknowledges NIH, DTRA, Broad, Oracle Cloud credits, MIT SuperCloud/Lincoln Lab, and the Antibiotics-AI Project. The JACS work has ERC breakingBAC and Merck Future Insight Prize support (C papers). These are concrete examples of well-funded antibiotic discovery competition; they do not establish that every natural-product generation topic requires industrial compute. Both depend on expensive chemical validation, which a string validity checker cannot replace.

Open issues illustrated by these papers include synthesis-aware generation with less chemist triage, small-data property control without oracle exploitation, novelty evaluated against all generative pretraining molecules, pinned releases with matching data counts, and microbial biosynthetic plausibility. Neither study establishes the last property.
