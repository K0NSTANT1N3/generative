# Boundary audit: EPOSMol and ShEPhERD

Audited 2026-10-23. **C** = confirmed at the primary source; **D** = arithmetic derived from a reported figure; **E** = estimate. These projects belong in the adjacent-work portion of the audit: EPOSMol optimizes general drug-like molecules with an NP-VAE backbone, while ShEPhERD explicitly demonstrates natural-product ligand hopping. Neither establishes microbial biosynthetic provenance for its generated compounds.

## Confirmed source details

EPOSMol's complete 11-page paper was inspected, including appendix B.1 where the training time is unusually explicit. The exact model/data setup is on page10; reward, docking, and diversity details are on pages7–9. The figure labeled NP-VAE does not mean the training set consists of 12M natural products: **12M is the parameter count**. The actual named training mixture is ZINC, DrugBank, and the custom50k set. Paper download size was **1,590,431 bytes** (C actual download), which is not the dataset size.

For ShEPhERD, all appendix text was inspected. Model sizes are in table8; training hyperparameters in table7; hardware/time in A.11; novelty definition in A.4; natural-product reference selection in A.2.3. The [current combined-model config](https://github.com/coleygroup/shepherd/blob/main/training/parameters/params_x1x3x4_diffusion_mosesaq_20240824.py) includes the batch reduction to42. Distinguish this repository detail from the paper's approximate48 batch. Epoch counts should remain **not reported** unless a completed checkpoint's metadata supplies an actual value; a maximum configured epoch limit would not establish elapsed training.

Primary source files retained under `/tmp/antibiotic-audit/`: `epos.pdf`, `shepherd.html`, `shepherd.txt`, `shepherd_readme.md`, `shepherd_license.txt`, `shepherd_tree.json`, and `shepherd_params.py`.

## Newly discovered 2026 follow-up

The official [ShEPhERD-2 repository](https://github.com/coleygroup/shepherd2) identifies **Interaction Profiles as a Universal Language for Generative Molecular Design with ShEPhERD-2**, by **Kento A. Abeywardane, Kenji Walker, Connor W. Coley**, MIT, bioRxiv2026, [DOI10.64898/2026.09.10.750648](https://doi.org/10.64898/2026.09.10.750648). Its README describes interaction-conditioned generation with pharmacophore prioritization, substructure constraints, profile composition, dual-target design, selectivity engineering, and modality hopping. Code is MIT; training data are linked as HDF5 through [Zenodo10.5281/zenodo.22675705](https://doi.org/10.5281/zenodo.22675705). The manuscript download was attempted and returned403; complete model/data/compute figures are not yet confirmed. It is in the requested date range, but should be labeled an identified adjacent follow-up rather than silently treated as fully audited.
