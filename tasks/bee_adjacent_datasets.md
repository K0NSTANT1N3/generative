# Bee-project adjacent efficacy/selectivity and pretraining sources

Scope: this is a bounded inventory of public chemical activity data, pesticide-likeness resources, and molecular pretraining corpora relevant to bee-safe pesticide discovery. “Efficacy” means an experimental pest/pathogen endpoint or activity assay. Pesticide-likeness, target predictions, docking, resistance, and toxicity records are different endpoints. **None of the resources below should be treated as bee-toxicity labels unless the cited assay actually measures bees.** A separate audit is handling bee-toxicity datasets; USDA bee/Varroa toxicity records are intentionally not duplicated here.

### PubChem query recipe (not a pre-curated benchmark)

Start with the [BioAssay search interface](https://pubchem.ncbi.nlm.nih.gov/bioassay/) or [PUG-REST assay search docs](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest-tutorial). Search terms and organism names separately, collect AIDs, inspect each assay Description and source, then download full CSV with the AID endpoint above. Report the exact AID list and number of result rows after structure resolution and unit/species filtering. In particular, avoid equating an in-vitro insect protein target assay with whole-organism mortality or field efficacy.

## Pesticide-specific generation / activity-oriented datasets

| Project | What it contributes | Availability and limits |
|---|---|---|
| [PestiGen: “Reinforcement learning-based generative artificial intelligence for novel pesticide design”](https://doi.org/10.1016/j.jare.2025.02.030) | Distinct project from the similarly named Pesti-Gen below. PestiGen-G uses a character-based Transformer plus REINFORCE to generate pesticide-like SMILES, conditioned by pesticide-likeness reward; PestiGen-S uses fragment generation/MCTS conditioned on target protein docking. Paper says it trained on ~1.5M standardized ChEMBL SMILES; PestiGen-S uses ~1M generated pesticide-like molecules; it also curates 154 HPPD inhibitors (<1 μM), 91 from literature and 63 internal. It reports a wet-lab HPPD inhibitor follow-up. | Article says web server is freely available at `https://dpai.ccnu.edu.cn/PestiGen/`; paper is open access CC BY-NC-ND 4.0. A direct downloadable training corpus, row-level license, bytes, and public repository were not confirmed in this pass. The 63 internal HPPD molecules are not publicly available by definition; exclude them from a reproducible training set. The 154 are target-enzyme activity data, not insect/mite efficacy and not bee safety. [Primary article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12685504/). |
| [Pesti-Gen: “Unleashing a Generative Molecule Approach for Toxicity Aware Pesticide Design”](https://arxiv.org/abs/2501.14469) | Taehan Kim and Wonduk Seo (2025 preprint; affiliations Berkeley and Peking University). VAE pretraining then toxicity-guided decoder fine-tuning, conditioned on livestock LD50 class and aquatic LC50 class. Primary text says pretraining on 50,000 ZINC SMILES for 30 epochs; custom Gyeonggi pesticide set is 56,360 records / 520 unique pesticides, often mixture formulations, with normalized toxicity grades. | The paper links ZINC source data to [aksub99/molecular-vae/data](https://github.com/aksub99/molecular-vae/tree/master/data) and identifies “Gyeonggi Province Pesticide Open Dataset,” but I did not confirm a direct original portal file URL, file bytes, or an explicit license for either derived corpus in the primary source. Paper preprint metadata/research copy says CC BY-NC-SA 4.0; verify current arXiv license separately before reuse. A runnable official project repo was not found. These are toxicity values, not insect efficacy or bee labels. |
| [Mos-Gen: “A Generative Molecular Framework for Mosquito Insecticide Design”](https://arxiv.org/abs/2606.01846) | Lina Wang and Yaning Cui (2026 arXiv preprint). Abstract confirms motif-aware Uni-Mol + VAE generation of disulfide-containing allicin derivatives; 14 selected compounds synthesized/tested (9 predicted positive, 5 negative), with 7/9 positive experimental hits and no observed activity in five negatives. This is mosquito efficacy, not bee toxicity. | Abstract/metadata are primary-confirmed; the accessible primary record in this pass did not expose training-corpus size, exact activity-labeled training count, dataset files, license, model code, hardware or training time. Do not rely on secondary-review numeric details as confirmed primary data. No repo link confirmed. For project planning, treat as insufficiently reproducible until the full PDF/supplement and data/code availability are inspected. |

These three similarly scoped names are not interchangeable: PestiGen (Elsevier 2025) uses RL plus target docking and has an internal HPPD subset; Pesti-Gen (Kim/Seo arXiv 2025) is toxicity-conditioned VAE; Mos-Gen (Wang/Cui arXiv 2026) targets mosquito-killing allicin derivatives and reports synthesis/assay validation.

## “AgroPAD” and related-name disambiguation

I did **not** find a primary pesticide activity database called “AgroPAD.” Search results for “AgroPad” primarily identify IBM/FAO’s soil/water colorimetric test-strip prototype, not molecular structures or bioassays ([FAO overview](https://www.fao.org/e-agriculture/news/agropad-real-time-location-and-chemical-analysis-soil-or-water-using-ai)). Likely intended pesticide resources are **InsectiPAD, HerbiPAD, FungiPAD, PADFrag**, and **Pesti-DGI-Net/CoPLE**; these mostly supply pesticide-likeness predictors, curated reference structures, or target predictions rather than standardized efficacy labels. A 2021 survey reports InsectiPAD 495 molecules and FungiPAD 377, but this is survey snapshot data, not a confirmed current downloadable export ([survey table](https://academic.oup.com/bib/article/22/6/bbab205/6294160)).

## Practical short list for a bee-safe project

1. Use PubChem AIDs for measured pest efficacy/selectivity where assays truly test the pest organism and have resolved structures; save exact source and endpoint metadata. Supplement with ChEMBL when assays are target-specific and matched selectivity panels exist.
2. Use COCONUT or an explicitly licensed ChEMBL subset for immediate general pretraining. Pin a version and file-level license. Avoid treating MOSES/ZINC as a no-conditions redistributable dataset without verifying upstream terms.
3. Keep separate targets in the learning schema: pest efficacy; bee acute/chronic toxicity; aquatic toxicity; pesticide-likeness; and biochemical target activity. The first two support a selectivity objective only when compatible species, exposure, units, and matched chemistry make comparison meaningful.
4. No ready-made open, unified Varroa/mosquito efficacy-plus-bee-selectivity molecular benchmark was confirmed in this bounded search. This is a concrete dataset gap; it does not mean no scattered assays exist.

Counts and sizes above are primary-source confirmed only where explicitly stated (e.g., MOSES, InsectiPAD, HerbiPAD, PADFrag, Pesti-Gen, COCONUT).
