# Generative modeling project research

Research notes for choosing a small, reproducible generative-modeling project, with a focus on glycans, RNA aptamers, and molecules with lower predicted honey-bee toxicity.

The `tasks/` directory contains supporting source audits, research notes, and utility scripts. The prompt and search-result files document the broader project-selection process.

## Status

This repository contains exploratory research, not a completed or experimentally validated model. Some notes are drafts or describe alternatives that were subsequently reconsidered. Statements about training feasibility, biological activity, data access, and licensing should be checked against the linked primary sources before implementation. A saved proposal is not a guarantee that it meets the intended compute budget.

The intended implementation budget is one free T4/P100-class GPU, approximately four GPU-hours including evaluation, and four weeks of solo implementation.

Downloaded datasets and third-party teaching materials are excluded. Follow the source links in the notes to obtain data under the original providers' terms.
